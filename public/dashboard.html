API Documentation

Complete reference for all UdaraAPI endpoints.

Authentication

All API endpoints (except /api/v1/stats) require an API key. Pass it as a header:

X-API-Key: ck_live_your_api_key_here

Or as a query parameter:

GET /api/v1/records?api_key=ck_live_your_key

📡 Stasiun Pemantau (Stations)

GET /api/v1/stations Daftar semua stasiun pemantau
ParameterTypeDefaultDescription
pageinteger1Page number
limitinteger50Per page (max 100)
provincestring—Filter provinsi (e.g. Kalimantan Tengah, Riau)
citystring—Filter kota (e.g. Palangka Raya, Pekanbaru)
searchstring—Cari nama/kota/provinsi
GET /api/v1/stations/provinces Daftar seluruh provinsi yang memiliki stasiun
GET /api/v1/stations/:id Detail stasiun spesifik
GET /api/v1/stations/:id/records Riwayat pembacaan kualitas udara stasiun

🌫️ Data Kualitas Udara (Records)

GET /api/v1/records Daftar data ISPU dengan filter lengkap
ParameterTypeDefaultDescription
pageinteger1Page number
limitinteger20Per page (max 100)
kategoristring—BAIK, SEDANG, TIDAK SEHAT, SANGAT TIDAK SEHAT, BERBAHAYA
provincestring—Filter provinsi
station_idinteger—Filter stasiun ID
tanggal_mulaiYYYY-MM-DD—Tanggal awal
tanggal_akhirYYYY-MM-DD—Tanggal akhir
sortstringtanggaltanggal, ispu, pm25, pm10
orderstringdescasc or desc
GET /api/v1/records/latest Kondisi udara terkini (snapshot 1 record per stasiun)
GET /api/v1/records/berbahaya Hanya data berkategori SANGAT TIDAK SEHAT & BERBAHAYA

🏷️ Platform Stats

GET /api/v1/stats Statistik platform (Public — Bebas API Key)

Response Format

All responses follow this standard format:

{ "success": true, "data": [...], "pagination": { "page": 1, "limit": 20, "total": 65, "total_pages": 4, "has_next": true, "has_prev": false } }

Error Codes

CodeMeaning
400Bad Request — Invalid parameters
401Unauthorized — Missing or invalid API key / JWT
403Forbidden — Key deactivated or account suspended
404Not Found — Resource does not exist
429Too Many Requests — Rate limit exceeded
500Internal Server Error
